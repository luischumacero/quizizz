# ⚡ EduQuiz Bolivia - Banco Oficial para Director de Unidad Educativa

Plataforma interactiva estilo **Quizizz** para el estudio y preparación del examen de competencia para **Director de Unidad Educativa (Estado Plurinacional de Bolivia)**.

Incluye **4,000 preguntas de selección múltiple (opciones A, B, C, D, E)** con fundamentación y justificación legal, distribuidas en **200 preguntas por tema** para los **20 temas oficiales** de la bibliografía ministerial.

---

## 🎯 Características Principales

1. **Estilo Quizizz Gamificado**:
   - Interfaz visual moderna, animaciones dinámicas, confeti y rachas de aciertos con llamas (🔥).
   - Opciones estilizadas con formas geométricas Quizizz:
     - **A**: Diamante (Rojo)
     - **B**: Círculo (Azul)
     - **C**: Triángulo (Verde)
     - **D**: Cuadrado (Ámbar)
     - **E**: Hexágono (Púrpura)
   - **Efectos de sonido sintetizados** (Web Audio API: aciertos, fallos, rachas; con botón para silenciar).
2. **Selección Flexible de Temas**:
   - Puedes elegir estudiar **1 tema, 5, 6 o los 20 temas simultáneamente**.
   - Filtros por categoría: *Normativa General*, *Normativa Específica*, *Técnico Pedagógico*.
   - Buscador rápido por palabra clave o número de ley.
   - Botones rápidos de "Seleccionar Todos" y "Deseleccionar Todos".
3. **Identificación del Tema en Cada Pregunta**:
   - En la parte superior de cada tarjeta de pregunta aparece claramente a qué normativa pertenece (ej: `[Normativa General] 4.2. Ley N° 070 Avelino Siñani - Elizardo Pérez`).
4. **Selector de Rango de Preguntas**:
   - Botones predefinidos para elegir **10, 20, 50, 100, 200 o Todas las disponibles**, además de un deslizador personalizado.
5. **Sin Límite de Tiempo (Untimed)**:
   - Responde a tu propio ritmo sin presión de tiempo de descuento.
   - Incluye un cronómetro de estudio opcional en la esquina para medir cuánto tiempo llevas estudiando.
6. **Dos Modos de Aprendizaje**:
   - 💡 **Modo Estudio**: Muestra retroalimentación inmediata al hacer clic, indicando la opción correcta y la justificación legal/técnica del artículo.
   - 📝 **Modo Simulacro**: Evaluación continua y fluida, con los resultados y explicaciones detalladas al finalizar.
7. **Pantalla de Resultados y Repaso Inteligente**:
   - Estadísticas de precisión, preguntas correctas/incorrectas y racha máxima.
   - **Botón "Repasar Solo las Incorrectas"**: Inicia automáticamente un nuevo quiz conteniendo exclusivamente las preguntas que fallaste.
   - Filtros en la revisión: ver todas, solo correctas o solo incorrectas.

## 🚀 Cómo Usar / Ejecutar el Sitio Web

El sitio es **100% estático (HTML5, CSS3, JavaScript puro)** y contiene los datos integrados, por lo que tienes 3 opciones para usarlo:

### Opción 1: Abrir Directamente en el Navegador (Sin instalar nada)
Simplemente haz **doble clic** en el archivo:
```text
C:\Users\Familia\Desktop\Preguntas para Estudiar\site\index.html
```
Se abrirá de inmediato en Google Chrome, Microsoft Edge o Firefox con todas las funciones activas.

---

### Opción 2: Servidor Local con Python (Recomendado)
Abre PowerShell en esta carpeta y ejecuta:
```powershell
py -3 -m http.server 8080 --directory site
```
Luego abre en tu navegador:
```text
http://localhost:8080
```

---

### Opción 3: Con Docker (Contenedor Nginx)
Si tienes **Docker Desktop** instalado y abierto, ejecuta en PowerShell:
```powershell
docker compose up -d
```
Accede desde tu navegador a:
```text
http://localhost:8080
```
Para detener el contenedor:
```powershell
docker compose down
```
